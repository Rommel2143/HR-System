# HR-System
HR-System
HR-System is a comprehensive human resource management system built using VB.NET. Designed to streamline HR processes, it provides efficient management of employee records, attendance, payroll, and performance tracking. The system integrates with MySQL for secure data storage and features a modern user interface powered by Guna UI.

Features
Employee Management: Create and manage employee profiles and records.
Attendance Tracking: Monitor employee attendance and leave.
Payroll Management: Generate payroll reports and manage salary details.
Performance Evaluation: Track and evaluate employee performance.
Database Integration: Uses MySQL for secure and reliable data storage.
User-Friendly Interface: Developed with Guna UI for a clean and intuitive user experience.
Technologies Used
VB.NET: The primary language used for development.
Guna UI: Provides a modern, user-friendly interface.
MySQL: Backend database for storing employee and HR data.
Excel Export: Export employee reports for further analysis.
